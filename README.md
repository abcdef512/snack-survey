# 우리 반 간식 선택 설문조사

## 실행 방법

Node.js가 설치된 환경에서 프로젝트 폴더를 열고 실행합니다.

```bash
npm start
```

브라우저에서 `http://localhost:3000`을 열면 됩니다.

## 사용 방법

- 반원: `간식 선택` 화면에서 카테고리를 누르고 상품을 여러 개 선택합니다.
- 카테고리를 이동해도 선택 목록이 유지되며, 선택 목록의 `×` 버튼으로 상품을 뺄 수 있습니다.
- 마지막에 `선택한 간식 한 번에 등록`을 누릅니다.
- 상품 목록은 첨부된 G마켓 HTML에서 추출한 활성 상품 493개입니다.
- 관리자: `관리자 정리` 탭에서 서버에 설정한 관리자 비밀번호를 입력합니다.
- 같은 상품을 여러 명이 선택해도 관리자 목록과 텍스트에는 한 번만 표시됩니다.
- `핀볼 입력용 텍스트`를 직접 정리한 뒤 복사합니다.
- 복사한 텍스트를 기존 Marble Roulette 입력란에 붙여넣어 순위를 매깁니다.
- 순위 위에서부터 예산에 맞춰 주문합니다. 이 사이트 자체에서는 룰렛을 돌리지 않습니다.

## 반별 방 코드

주소 뒤에 `?room=원하는방코드`를 붙이면 반별로 데이터를 분리할 수 있습니다.

예: `http://localhost:3000/?room=ssafy-16-seoul`

## Render에 배포하기

이 프로젝트는 브라우저에서만 실행하는 정적 페이지가 아니라 응답을 저장하는 Node.js 서버이므로 `Static Site`가 아니라 `Web Service`로 배포해야 합니다.

1. 프로젝트 파일을 GitHub 저장소에 올립니다.
2. Render에서 `New → Web Service`를 선택하고 저장소를 연결합니다.
3. 다음 값을 입력합니다.

```text
Build Command: npm install
Start Command: npm start
```

4. 별도 환경변수 설정 없이 실행됩니다. 저장소는 반드시 Private으로 유지하세요.
5. 배포가 끝나면 생성된 공개 주소를 반원들에게 공유합니다.

현재 응답은 `data.json`에 저장합니다. Render 기본 파일시스템은 재배포나 재시작 때 초기화될 수 있으므로, 실제 운영에서는 Render Postgres 같은 데이터베이스를 연결하거나 영속 디스크를 사용해야 합니다. `DATA_FILE=/var/data/data.json`처럼 저장 경로를 환경변수로 바꿀 수 있게 되어 있습니다.
